# BenQ RE05AC｜沉浸式網頁

## 開啟方式

解壓縮後，開啟 index.html 即可瀏覽。請保留同一資料夾內的 styles.css、app.js、favicon.svg 與 assets 資料夾。

## 上傳至 GitHub Pages

1. 將解壓縮後的全部檔案上傳到 GitHub 儲存庫根目錄，包含 assets 資料夾。
2. 在儲存庫 Settings → Pages，選擇 Deploy from a branch。
3. 選擇 main 分支與 / (root)，儲存後等待 GitHub 完成部署。

本壓縮檔是可部署的網站檔案；下載與解壓縮不會自動建立 GitHub 專案或發布網站。

## 內容

共 9 個章節，涵蓋原始 11 頁簡報的教學應用主題。包含情境切換、互動白板、分屏配置示意、AI 應用切換、尺寸比較、簡報模式與現勘清單。

白板、分屏配置與 AI 應用為網頁互動示意，並非 BenQ 軟體的實際操作介面。

產品規格於 2026-10-29 對照 BenQ 台灣官方資訊。售價取自 2026.10 原始推廣簡報，實際採購與安裝費用依專案報價確認。

產品與教學情境圖片沿用原簡報素材。
