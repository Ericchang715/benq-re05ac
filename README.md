# BenQ RE05AC｜大專院校互動教學提案

## 這個壓縮檔包含什麼？

這是以 2026-10-29 所保存的「BenQ RE05AC｜大專院校互動教學提案」網站內容紀錄和原始 11 頁 PowerPoint 素材，重新製作的靜態網站。**並非原 ChatGPT Site 的 HTML / CSS / JS 完整匯出，畫面和互動效果不保證與原站完全相同。**

- `index.html`：首頁及九大主題區塊
- `styles.css`：桌機和手機版樣式
- `script.js`：互動元件（情境切換、白板畫線、分屏切換、AI 功能選擇、尺寸比較、現勘清單、簡報模式）
- `assets/`：本機圖片和網站圖示（照片由原簡報素材轉製）

## 開啟方法

1. 解壓 ZIP 壓縮檔，保留原本的資料夾結構。
2. 直接雙擊 `index.html`，即可使用現代瀏覽器開啟。內容及圖片不需連網。
3. 「BenQ 官方介紹」等外部網站連結需要網路連線。

## 上傳到 GitHub Pages

1. 在 GitHub 建立公開儲存庫，或選擇已有儲存庫。
2. 將 `index.html`、`styles.css`、`script.js` 與整個 `assets` 資料夾放在儲存庫根目錄。
3. 前往 GitHub 儲存庫的 `Settings → Pages`，在 `Build and deployment` 選擇 `Deploy from a branch`、`main` 和 `/(root)`，並儲存。
4. 等待 GitHub Pages 完成部署，使用 Pages 顯示的連結開啟。
